# R402 多维因子库扩容 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

## Goal

检验把因子集从 4–8 腿扩展到 10–12 腿是否提升长期、验证和近一年表现，而不是简单堆因子。

## Constraints

- 只用已注册/portfolio-ready 因子，不新增公式。
- 保留至少 4 个现有核心成员，控制共线性和容量。
- 统一 2× 主成本、3× 压力、HS300 真实基准、无杠杆。
- 不生成订单或生产配置。
