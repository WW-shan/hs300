# R534B Regime Coverage Amendment

## 背景

R534A 完成 6 个训练规则正式回测并选出规则后，在准备确认矩阵时失败：

```text
市场环境数据覆盖不完整: 缺少前一交易日环境 2026-10-15
```

未生成 R534A result，也未读取验证、近一年或压力收益。

## 根因

项目 enriched 股票交易日历包含 2026-10-15，但 `regime_history` 缺少该日。R534A 把确认截止日设为 `2026-10-21`，T-1 对齐在 2026-10-16 需要 2026-10-15 状态，因此 fail-closed 拒绝。

## 修正

R534B 把确认截止日移到最后一条完整 T-1 链的日期：

```text
2026-10-14
```

不补值、不前填 2026-10-15，不改变训练窗口、规则、bootstrap 或门禁。近一年窗口因此为 2025-10-14 至 2026-10-14。

## 不变项

- 六因子、10 仓/60 日不变；
- 6 个 regime 规则不变；
- 训练期 2022-05-05 至 2024-12-31 不变；
- 5000 次 block-20 bootstrap 不变；
- v2 门禁和 5× warning-only 不变；
- R534/R534A 原预注册和失败记录保留。
