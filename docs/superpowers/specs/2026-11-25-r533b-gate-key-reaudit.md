# R533B 正式门禁字段重审

## 背景

R533A 的正式回测证据有效，但门禁适配层把回测指标名直接传给 `gate_policy_v2`：

- 回测输出 `annual_return`；
- 回测输出 `max_drawdown`；
- v2 政策读取 `annual`；
- v2 政策读取 `mdd`。

因此 R533A 错误地报告了 annual/MDD 门禁失败，尽管主组合 2× 年化 14.33%、MDD -14.49% 实际满足 v2 要求。

## 处理

R533B 只读取冻结的 R533A result 和 gate policy，重新映射：

```text
annual_return -> annual
max_drawdown -> mdd
```

不重跑回测，不改因子、参数、窗口、成本或阈值。R533A 原始拒绝结论和文件保持不变。

## 修正后事实

- 主组合 2× 年化：14.33%
- 主组合 2× Sharpe：1.03
- 主组合 2× MDD：-14.49%
- 验证期年化：1.63%
- 近一年：-4.82%
- 3× 压力近一年：-5.58%
- 5× 成本：仅诊断，无 warning，无硬否决

修正后仍拒绝，失败仅为：

- `core_2x.recent_return`
- `stress.recent_return`

## 解释

问题已从“全样本/回撤/对照都不合格”收敛为“最近一年收益为负”。后续优化应围绕近期状态识别、动态仓位、风险预算或新增情绪/周期因子，不应继续重复全样本参数搜索。

## 边界

R533B 是从冻结结果派生的门禁重审，不产生新的回测、订单、纸面目标或 active version。
