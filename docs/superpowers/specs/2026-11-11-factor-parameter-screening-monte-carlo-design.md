# 因子筛选与参数蒙特卡洛系统设计

## 1. 目标

把当前 223 个注册因子从“可查询的因子母集”升级为可持续研究的因子库：

1. 自动识别哪些因子属于同一参数族；
2. 对参数化因子执行确定性参数搜索；
3. 用训练/检验分段、行业与规模中性化、多重检验和蒙特卡洛验证参数稳定性；
4. 对稳定参数执行与现有 watch 组合的边际贡献测试；
5. 只把通过增量验证的因子写入 watch 因子集，不自动激活或生成交易信号。

本系统解决的是“参数搜索 + 稳健性验证 + 组合增量”三件事，不是简单地把所有
因子都调一遍参数。

## 2. 当前基线

- 注册因子：223。
- 因子类型：base 138、virtual 52、custom 19、composite 14。
- 数据类别：price 109、financial 38、flow 36、macro 20、sentiment 10、industry 10。
- 扩展字段：109，其中数据审计通过 102，unknown 7。
- 当前统一横截面扫描：64 个因子，12 个 promising。
- 当前市场级扫描：38 个因子，无 5 日 FDR 通过项。
- 当前参数蒙特卡洛：8 个价格风险家族、32 个参数点。
- 当前组合：`multi_dimension_v1` 8 个 watch 成员，`active_version=null`。

## 3. 非目标

- 不自动激活策略，不生成纸面目标或订单。
- 不修改历史因子 ID 的经济含义。
- 不把同族的不同窗口当作独立发现。
- 不因为单次组合回测收益最高就选定参数。
- 不用未来数据、快照数据或未审计字段参与历史参数搜索。
- 不在 Weak Window 上直接拟合专用参数。

## 4. 因子分类

### 4.1 分类结果

每个注册因子必须归入以下状态之一：

| 状态 | 含义 |
| --- | --- |
| `tunable` | 有明确、可重算的参数语义，可进入参数搜索 |
| `fixed` | 无参数，或参数不是窗口/阈值，只做普通筛选 |
| `grouped` | 已归入某个参数族的成员，不单独调参 |
| `blocked` | 数据、PIT、定义或计算链不满足要求 |
| `unclassified` | 有参数迹象但尚未被显式参数族覆盖，fail-closed，禁止调参 |

`unclassified` 不能自动降级为 `fixed`。

### 4.2 参数族原则

参数族是调参的最小单位。一个参数族包含：

- 相同经济含义；
- 相同方向；
- 相同的计算模板；
- 仅一个或少数明确参数不同；
- 可以生成唯一变体 ID。

例如以下因子归为一个参数族：

```text
ext_alt_hs300_idio_vol_20d_low
ext_alt_hs300_idio_vol_40d_low
ext_alt_hs300_idio_vol_60d_low
```

不能把 20、40、60 日版本当成三个独立因子重复计入有效因子数量。

## 5. 参数族注册表

新增持久化文件：

```text
data/factor_research/parameters/families.json
```

契约：

```json
{
  "schema_version": 1,
  "families": [
    {
      "family_id": "idio_vol",
      "label": "HS300 残差低波",
      "data_class": "price",
      "cross_section_type": "stock_cross_sectional",
      "direction": "high",
      "evaluator": "residual_volatility",
      "parameter_name": "window",
      "parameter_grid": [10, 20, 40, 60, 120, 240],
      "current_parameter": 60,
      "minimum_history": 240,
      "neutralization": ["industry", "size"],
      "member_factor_ids": [
        "ext_alt_hs300_idio_vol_20d_low",
        "ext_alt_hs300_idio_vol_40d_low",
        "ext_alt_hs300_idio_vol_60d_low"
      ],
      "status": "tunable",
      "evidence_refs": []
    }
  ],
  "unclassified_factor_ids": []
}
```

约束：

- `family_id` 必须唯一，`member_factor_ids` 不得跨参数族重复，
  `evaluator` 必须引用已注册且可执行的评估器。
- 每个参数网格必须包含当前参数。
- 参数网格只能包含正整数，并且升序排列。
- 同一因子不能同时属于两个 `tunable` 参数族。
- `member_factor_ids` 必须全部存在于当前 catalog snapshot。
- 新 catalog 出现带窗口数字但未登记的参数族时，必须进入
  `unclassified_factor_ids`，并阻止批量发布。

## 6. 参数搜索

### 6.1 样本口径

- 全样本起点：2021-06-01。
- 训练段：2021-06-01 至 2024-12-31。
- 检验段：2025-01-01 至最新可用交易日。
- 近一年段：2025-10-14 至最新可用交易日。
- 股票池：当前 HS300；报告必须保留幸存者偏差标记。
- 最小横截面：30 只。
- 默认收益周期：5 个交易日。
- 市场级参数族使用时间序列 rank regression；其余参数族使用横截面 Rank IC。

### 6.2 参数候选

每个参数族至少评估：

- 当前参数；
- 注册表中的全部网格点；
- 当前参数左右相邻点。

参数网格必须预先固定。禁止根据单次结果动态追加“看起来更好”的参数点。

### 6.3 变体身份

参数搜索不能覆盖原因子定义。每个候选参数生成独立变体 ID：

```text
{family_id}__p_{parameter}
```

变体只存在于研究结果和候选因子集中，并记录：

- `family_id`
- `parameter`
- `definition_fingerprint`
- 输入数据指纹
- 方法版本
- 生成时间

## 7. 稳健性验证

### 7.1 基础统计

每个参数点必须计算：

- 全样本 Rank IC；
- 训练段 Rank IC；
- 检验段 Rank IC；
- 近一年 Rank IC；
- 逐年 IC 与同号率；
- Newey-West HAC t 值；
- 参数族内 BH-FDR q 值；
- 行业中性后的方向 IC；
- 规模中性后的方向 IC；
- 行业 + 规模中性后的方向 IC；
- 数据覆盖率和样本日期数。

市场级参数族使用方向 beta、HAC t、近一年 beta 和 20 日 beta 作为等价统计。

### 7.2 参数平台

一个参数只有满足以下条件才算 `robust_plateau`：

- 参数网格至少包含三个点；
- 当前参数位于网格内部时，左右邻点均存在且方向一致；
- 当前参数位于网格端点时，向网格内部最近的两个点均存在且方向一致；
- 中间参数点前后相邻点均存在且方向一致；
- 全样本方向 IC 为正；
- 训练段和检验段方向 IC 均为正；
- 不允许通过空缺邻点伪造平台。

只有一个参数点的参数族不判定为 `robust_plateau`，只能标记为
`single_point_unverified`。

平台判定只使用预先登记的网格，不得事后补点。

### 7.3 蒙特卡洛

蒙特卡洛用于估计参数估计的不确定性，不直接替代参数搜索。

两阶段执行：

1. 所有参数点：1000 次 moving-block bootstrap；
2. 入围参数点：5000 次 moving-block bootstrap。

默认参数：

- 主 block size：20 个交易日；
- 初筛 replication：1000；
- 决赛 replication：5000；
- 固定随机种子：由 `research_id + family_id + parameter` 派生；
- 置信区间：95%；
- 同时报告 `prob_positive`；
- 决赛参数额外评估 block size 10 和 40 的敏感性。

通过条件：

- `ci_low > 0`；
- 训练段与检验段同号；
- 行业 + 规模中性后的全样本方向 IC 为正；
- 参数族内 q 值不高于 0.10。

### 7.4 参数推荐

在通过稳健性条件的参数中，按以下顺序选择：

1. 最大化 `min(train_directional_ic, test_directional_ic)`；
2. 若并列，选择 5000 次 bootstrap `ci_low` 更高者；
3. 若仍并列，选择更接近当前参数者。

不直接按组合累计收益选择参数。

## 8. 组合增量验证

参数稳定只代表单因子有效，不代表应该加入组合。

对每个推荐参数执行：

1. 与当前 `multi_dimension_v1` 全体因子计算平均绝对相关和最大相关；
2. 在现有组合上加 20% 候选权重，计算边际 IC；
3. 用等权重新归一后的新组合跑真实 T+1 回测；
4. 比较全周期、近一年、2x/3x 成本、滚动一年、Sharpe 和最大回撤；
5. 记录新增因子是否改变唯一负滚动窗口的表现。

进入 watch 的必要条件：

- 边际 IC 为正；
- 边际 IC 的 NW p 值不高于 0.10；
- 与现有任一因子的最大绝对相关不高于 0.90；
- 全周期和近一年组合回测没有同时恶化；
- 参数稳定性结论未在增量测试后失效。

不满足者保留在参数库中，标记 `rejected_incremental`，不得为了凑数量加入组合。

## 9. 状态机和输出

### 9.1 因子状态

```text
registered
  -> audited
  -> parameter_stable
  -> incremental_positive
  -> watch
```

失败分支：

```text
audit_failed
parameter_rejected
incremental_rejected
blocked
```

`active` 不属于本系统自动输出。它必须继续经过历史成分、逐字段 PIT、容量和纸面
跟踪。

### 9.2 研究产物

每次运行生成：

- 参数族注册表校验报告；
- 参数搜索结果 JSON；
- 每个参数点的统计和 Monte Carlo 结果；
- 参数推荐表；
- 组合增量结果；
- 可读 Markdown 报告；
- ResearchLedger 记录；
- 所有产物 SHA-256。

默认目录：

```text
data/factor_research/research/parameters/
```

文件命名必须包含方法版本和运行 ID，不允许覆盖历史结果。

## 10. 分批执行计划

### P0：参数族清点与分类

交付：

- `families.json` schema 与校验器；
- 223 个因子的分类覆盖报告；
- `tunable`、`fixed`、`grouped`、`blocked`、`unclassified` 数量；
- 第一批可执行参数族清单。

退出条件：

- 每个注册因子都有明确分类；
- 没有静默遗漏的窗口型因子；
- 单元测试覆盖重复归属、缺失因子、非法网格和未分类阻断。

### P1：现有 8 个价格风险族统一跑批

范围：

- 残差低波；
- Corwin-Schultz 价差；
- 波动率稳定性；
- 市场下跌 beta；
- 价格延迟；
- 趋势效率；
- 风险调整动量；
- beta 不对称。

交付：

- 每族参数网格；
- 训练/检验/近一年统计；
- 1000 次初筛和 5000 次决赛 Monte Carlo；
- 推荐参数；
- 参数平台报告。

退出条件：

- 8 族均有明确 `recommended` 或 `rejected`；
- 推荐参数不共享偶然的单点峰值；
- 研究产物和台账哈希通过。

### P2：内置窗口型因子

范围：

- 动量：5/10/20/60/120 日；
- 均线偏离：MA/EMA 5/10/20/60；
- 波动率与布林带；
- 价格位置：60/240 日；
- 流动性、成交额、换手率和 Amihud；
- 涨停基因窗口。

交付：

- 同族归并清单；
- 参数网格和推荐参数；
- 与 P1 结果的跨族相关性矩阵；
- 参数过多或无法重算的因子进入 `fixed` 或 `blocked` 并说明原因。

退出条件：

- 不把同一动量的多个窗口重复计为独立有效因子；
- 每个推荐参数均可追溯到确定公式；
- 任何 `unclassified` 参数族都阻止发布。

### P3：扩展数据窗口因子

范围：

- 董监高增减持；
- 龙虎榜；
- 回购与大宗交易；
- 分析师评级与业绩预告；
- 行业动量/RPS/宽度；
- 市场状态与宏观变化窗口。

交付：

- 事件窗口与衰减参数网格；
- PIT 与数据覆盖复核；
- 参数稳定性结果；
- 市场级因子只进入 conditioner 候选，不直接进入股票 alpha 腿。

退出条件：

- unknown 字段不参与调参；
- 数据陈旧字段保持 blocked；
- 市场级因子没有通过 FDR 时不得写成有效择时因子。

### P4：阈值型与事件型因子

范围：

- 股息率阈值；
- 基金持仓拥挤阈值；
- 融资余额变化阈值；
- 股东结构变化阈值；
- 事件衰减窗口；
- 事件后持有期。

交付：

- 阈值搜索器；
- 分位数/绝对阈值两种口径；
- 稳定性平台和样本外结果。

退出条件：

- 阈值选择不直接最大化组合收益；
- 极窄平台中的“最佳阈值”标记为不稳定；
- 事件型因子的公告日 PIT 可追溯。

### P5：全库增量筛选

范围：

- 汇总 P1-P4 所有 `parameter_stable` 候选；
- 去重同一经济含义的参数族；
- 与当前 `multi_dimension_v1` 做边际 IC 和组合回测；
- 对高分候选做 leave-one-out 和 single-factor 拆解。

交付：

- 候选增量排名；
- 接受和拒绝原因；
- 新 watch 因子集版本；
- 负知识台账。

退出条件：

- 新因子集只含边际贡献为正的成员；
- 高相关重复因子被去重；
- `active_version` 仍为 null；
- 每个新增成员都有参数、统计、增量、回测和证据引用。

### P6：继续扩库的自动闭环

交付：

- 新 catalog snapshot 后自动发现新增候选；
- 自动识别未分类参数族；
- 自动生成待跑清单；
- 自动阻止未审计、未分类或未通过 PIT 的因子进入组合；
- 研究运行与 ResearchLedger 自动绑定。

退出条件：

- 新增因子不会绕过筛选链；
- 重复运行保持幂等；
- 历史参数结果不被覆盖；
- 失败任务留下明确负知识而不是静默跳过。

## 11. 数据与计算性能

- 参数搜索复用同一份价格、市场收益和扩展数据面板。
- 每个参数族的原始价格和行业/规模字段只加载一次。
- 参数计算优先使用 Polars 向量化；蒙特卡洛只对每日统计序列重采样。
- 初筛与决赛分离，避免所有参数点都跑 5000 次。
- 单次研究结果必须能在无网络环境下复现。
- 所有随机过程使用确定性种子。

## 12. 测试矩阵

### 单元测试

- 参数族 schema 校验；
- 重复 family、重复成员、缺失因子、非法网格；
- `unclassified` fail-closed；
- 参数平台边界；
- 推荐参数排序稳定性；
- moving-block bootstrap 确定性；
- 中性化前后口径；
- 参数变体 ID 唯一性；
- 边际 IC 符号和相关性拒绝。

### 集成测试

- 合成面板上运行一个参数族全流程；
- 训练/检验切分无未来数据；
- P1 全部 8 族可生成同一 schema；
- 结果写入 ResearchLedger 且 SHA 一致；
- 重复运行幂等，不覆盖旧产物；
- catalog 新增加未分类窗口因子时阻止发布。

### 回归测试

- 现有 `multi_dimension_v1` 保持 watch；
- `core_v1` 保持 watch；
- `active_version=null`；
- 现有因子集版本不变；
- 全量后端测试通过；
- Ruff 和 `git diff --check` 通过；
- 机器绝对路径不进入研究产物。

## 13. 验收标准

一期完成必须同时满足：

1. 223 个因子全部有分类状态；
2. 没有重复成员或静默遗漏的参数族；
3. P1 的 8 个参数族全部产出推荐或拒绝结论；
4. 每个推荐参数都有训练、检验、近一年、中性化、FDR 和两阶段 Monte Carlo；
5. 每个候选加入组合前都有边际 IC 和相关门槛；
6. 新 watch 成员可追溯到具体参数和证据；
7. 不产生 active 版本或订单；
8. 全量测试、研究幂等和台账哈希验证通过。

## 14. 风险与边界

- 当前 HS300 名单回填历史仍存在幸存者偏差。
- 财务和扩展字段的 PIT 主要为声明级证据，逐字段核验仍是后续硬门槛。
- 参数网格仍可能遗漏真实平台；结果是有限网格上的稳健性，不是连续最优。
- Monte Carlo 重采样历史路径，不产生新市场样本。
- 组合增量测试使用当前市场和行业数据，不能证明未来可持续。
- 本系统只负责把候选推进到 watch；任何 active 结论必须另行验证。
