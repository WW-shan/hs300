# R2 · 深研轮 (2026-10-14 冷启动) — 挖掘模块驱动的更严谨一轮

## 动机 (为什么重做)

v1 的教训: 全样本 +32.6% 但**滚动起始日为负**(2026-05 起), alpha 只集中在 2025-11~2026-06;
成因是 (a) 只用 1 年数据, (b) 单边动量暴露, (c) 无环境离场。本轮针对这三点重做。

## 数据扩充 (本轮前置)

原数据仅 2025-10-14~2026-10-14 (243 交易日)。本轮通过系统盘后管道回补到
**2021-06-01 起** (约 5 年 / ~1280 交易日), 同时回补指数与市场环境(regime),
使系统**挖掘模块达到可用门槛** (strict 需 1164 根, balanced 需 786 根)。

## 研究路径 (严格按项目协议)

1. **因子挖掘**: 用系统挖掘模块 `/api/backtest/mining/runs` (嵌套 walk-forward,
   3+ outer folds, inner/outer 之间 purge 30 交易日 + embargo 5), 股票池 = HS300 当前成分。
   因子相关性去重 `correlation_threshold`, 组合上限 4 因子, beam 搜索。
2. **候选晋级**: 只用通过系统 candidate gate 的候选; `promote` 后 `publish` 为独立策略。
3. **策略回测**: 用 `/api/backtest/strategy/run` 在 HS300 口径下回测, 对照 HS300 指数。

## 判定门槛 (先于结果写下, 结果出来后不得修改)

| # | 门槛 | 阈值 |
| --- | --- | --- |
| G1 | 系统 candidate gate | 必须 qualified |
| G2 | 全区间年化超额 (vs 沪深300指数) | > 0 |
| G3 | 全区间最大回撤 | ≤ 25% |
| G4 | 全区间 Sharpe | ≥ 0.8 |
| G5 | 分年正收益比例 | ≥ 70% |
| G6 | 最差单年收益 | > -12% |
| G7 | 样本外 (挖掘 outer test 汇总) 收益 | > 0 |

**回退线** (触发即回退/换方向):
- 全区间年化超额 ≤ 0, 或
- 最大回撤 > 35%, 或
- 分年正收益比例 < 50%, 或
- 样本外为负且全样本为正 (典型过拟合信号)。

**停止规则**: 连续 2 轮无改善, 或达成全部门槛, 或满 8 轮强制复盘。

## R2 结果 (2026-10-14 实测)

### 数据扩充(前置)

原数据仅 243 交易日 (2025-10-14 起)。本轮把 **300 只 HS300 成分 + 5 个核心指数**的历史
补到 **2021-06-01**(共 1301 交易日 / 5.3 年), 用与盘后管道同源的服务
(`kline_sync.sync_and_persist_daily_batch` / `sync_adj_factor` / `index_sync` /
`indicators.run_pipeline(symbols=...)`), 内存可控(全市场 5 年重建在本机 15GB 内存下会 OOM,
故只回补研究口径需要的 300 只)。

### 因子层结论 (2021-06 ~ 2026-10, HS300, 月度 5 分组, 全 77 因子)

跨年一致(≥5/6 年同号)、|IC| 较大的因子(按方向):

| 方向 | 因子 | 全区间 IC | 多空 | 说明 |
| --- | --- | --- | --- | --- |
| 低值好 | `log_amount` / `amount_mean_20d` | -0.064 / -0.069 | -0.34 / -0.35 | 低成交额溢价 |
| 低值好 | `momentum_5d` / `momentum_10d` | -0.062 / -0.059 | -0.46 / -0.43 | 短期反转 |
| 低值好 | `ma10_bias` / `ema10_bias` | -0.053 / -0.051 | -0.41 / -0.34 | 均线乖离反转 |
| 低值好 | `annual_vol_20d` | -0.043 | +0.32 | 低波动 |
| 低值好 | `log_float_mv` | -0.033 | **-0.61** | 指数内小市值 |
| 高值好 | `amihud_20d` | +0.048 | +0.49 | 非流动性 |
| 高值好 | `mom_accel_20_60` | +0.044 | +0.22 | 动量加速 |
| 高值好 | `overnight_ret_20d` | +0.033 | +0.35 | **唯一 6 个日历年 IC 全为正/近全为正的因子** |

**负知识**: 2021-2024 强、2025 起衰减 —— `log_amount` / `amihud` / `momentum_5d` /
`ma10_bias` 在 2025 年 IC 都翻到 ~0 或转负; 2026 年 `amihud` 转负而 `overnight_ret_20d`
反而走强(+0.133)。**没有任何单一因子在两个子区间都强。**

### 失败的假设(值钱的负结果)

**假设 H1**: 低关注度+小市值+低波动 三维等权(用 DSL 自定义因子
`uf_low_amount` / `uf_small_mv` / `uf_low_vol` 转成"越大越好")。

- 开发区间 2021-06~2024-12: **+209.1%, DD -16.4%, Sharpe 1.66, Calmar 2.35**, 逐年
  +18.4% / +15.9% / +32.3% / +70.1% —— 开发区间内四个日历年全为正。
- 留出集(封存, 只跑一次)2025-01-01~2026-10-14: **+5.8%, DD -22.8%, Sharpe 0.29**;
  同期沪深300 +7.2% → **超额 -1.4pp, G2/G4/G5 不通过**。
- 结论: 低风险溢价在 2025 年以后明显衰减, 该假设**未通过留出集**, 不能当作"稳妥"定型。

**假设 H2**: 年度滚动 walk-forward(每年只用截至上一年底的数据按 |IR| 选前 4 因子,
方向取 IC 符号, 等权) 2022~2026: -6.0% / +21.3% / +43.8% / +12.2% / -13.3%,
**链式 +59.4%, 3/5 年为正**。诚实结论: 该因子库上的可持续 alpha 远低于样本内表现。

## 附: 依赖的自定义因子定义 (data/user_data/custom_factors/, gitignored, 需一并备份)

重建方式: `POST /api/factors/custom` body `{"id","label","group","formula","description","direction":"high"}`,
或直接把下面 JSON 写到 `data/user_data/custom_factors/<id>.json` 后重启后端。

```json
[
 {"id":"uf_low_amount","kind":"custom","label":"低成交额(流动性折价)","group":"流动性",
  "formula":"0 - log(amount + 1)","description":"成交额越低越好 (内联 log, 不引用虚拟因子)","direction":"high","status":"draft"},
 {"id":"uf_small_mv","kind":"custom","label":"小市值(指数内)","group":"规模",
  "formula":"0 - log(close * volume / turnover_rate)","description":"流通市值越小越好 (由换手率反推)","direction":"high","status":"draft"},
 {"id":"uf_low_vol","kind":"custom","label":"低波动","group":"波动率",
  "formula":"0 - annual_vol_20d","description":"20日年化波动越低越好","direction":"high","status":"draft"}
]
```

**坑 (已踩)**: DSL 公式**不能引用虚拟因子**(如 `log_amount` / `log_float_mv`) —— 编译通过,
但回测评分阶段 `materialize_scoring_columns` 只物化评分名单里的列, 依赖的虚拟因子不会被物化,
`frame_transform` 返回 None → 该因子被**静默丢弃**(评分只剩其它因子, 结果与不写它完全一致)。
判断方法: 回测返回的 `factor_attribution.factors` 里没有这个因子名就是被丢了。
公式必须内联成基础列 + 算子(见上面的 `log(amount + 1)` / `log(close*volume/turnover_rate)`)。
引用**基础/存储列**(momentum_10d、annual_vol_20d、turnover_rate)的公式没有这个问题。
