# R336 结果：Top20 修复了宽度但没有修复 5× 成本脆弱性

R336 把 R334 的 Top10 扩展为 Top20，保持 1/3 权益上限、三资产防守桶和全部规则不变。

## 2×/5× 结果

| 项目 | 2× | 5× |
| --- | ---: | ---: |
| 完整路径收益 / 年化 | +59.69% / +9.38% | **+45.96% / +7.52%** |
| Sharpe / MDD | 1.0577 / -8.83% | **0.8621 / -10.49%** |
| 2022 / 2023 | +1.99% / +8.02% | +0.71% / +6.46% |
| 股票数 | 233 | 233 |
| 前五净贡献 | 45.62% | **168.04%** |
| 黄金贡献 | 未单独列示 | **50.38%** |

- 参数平台：9/9 overlay 和 3/3 joint target 全过。
- 3× 保守、4×、5× 收益/回撤全部通过。
- 三个单资产替换和五个 fresh-start 全部通过。
- 但 5× 净集中度失败：top1 44.16%、top3 111.47%、top5 168.04%；黄金贡献 50.38% 也超过 50% 资产贡献门槛。

Top20 把 2× 下的前五净贡献从 61.08% 降到 45.62%，但 5× 下股票净收益太薄，净贡献指标反而更极端；因此 Top20 不是 5× 的修复方案，`selected=null`。

最终结论：在原始严格门槛下没有 5× 成本仍全部通过的策略。R334 是 2×/4× 成本下最好的研究候选，但当前应保持 `research_only_cost_fragile`，不能进入生产或纸面执行。

证据：`evidence/r336_top20_cap33.json`、`evidence/r336_top20_cap33_preregistration.json`、`evidence/r336_preregistration_amendment_A1.json`。
