| 项目 | 4× 成本 | 5× 成本 |
| --- | ---: | ---: |
| 完整路径收益 / 年化 | +64.54% / +10.01% | **+60.49% / +9.49%** |
| Sharpe / MDD | 1.1103 / -9.50% | **1.0579 / -9.75%** |
| 2022 / 2023 | +1.19% / +8.25% | **+0.82% / +7.82%** |
| 近一年收益 | 未单列 | **+3.41%** |

收益和回撤在 4×/5× 都通过，但 5× 的股票净收益集中度失败：

| 5× 集中度 | 结果 | 门槛 |
| --- | ---: | ---: |
| 最大单票净贡献 | **26.61%** | <=25% |
| 前三净贡献 | **63.68%** | <=55% |
| 前五净贡献 | **91.66%** | <=75% |
| 股票净/毛收益 | 18.88% | - |
| 前五/毛利润贡献 | 17.30% | 诊断项 |

这里要区分结构事实和口径限制：股票净利润被 5× 成本压到毛利润的 18.88%，所以“净利润集中度”分母很小并迅速放大；前五名占毛利润只有 17.30%，股票宽度并未坍缩。但 R335 预注册使用的是净收益口径，结果必须按原门槛判失败。

按预注册，R334 从 `candidate_for_paper_trading_review` 降级为 `research_only_cost_fragile`。4× 成本仍通过，5× 失败；不能因 4× 好看就忽略 5×。
