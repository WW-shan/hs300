# 研究门禁政策 v2

生效日期：2026-11-10
状态：事后门禁纠偏（post-hoc gate-policy correction）

实现：`backend/app/research/gate_policy_v2.py`；机器可读政策：`gate_policy_v2.json`。

## 为什么改

旧研究把多种不同性质的约束混成一张硬门槛表，导致部分本来接近可用的策略被直接否决。最明显的问题有四个：

1. 把 5× 交易成本误解成杠杆。实际策略始终多头、非负权重、总目标权重不超过 100%、不使用融资。
2. 5× 成本把组合净利润压得很薄，top1/top3/top5 净收益占比的分母失真，不能独立作为否决条件。
3. 年化 12%、Sharpe 1.25、2022 必须非负、6 个起始相位至少 5 个为正，被反复作为统一门槛，过严且不符合不同研究假设。
4. 缺少分层：数据完整性、现实成本、严重压力、集中度和极端诊断被混成同一优先级。

## 分层门槛

### 1. 数据完整性（强制）

必须满足 PIT 财报、历史 HS300 成分、无未来函数、T+1 开盘成交、涨跌停/停牌约束、输入哈希稳定和无杠杆。

### 2. 2× 现实成本（强制）

- 年化收益 >= 8%
- Sharpe >= 1.0
- MDD 不深于 -20%
- 2022 收益 >= -5%
- 2023 收益 >= 0
- 近一年 > 0
- 至少 4/6 起始相位为正，且中位数 > 0
- 匹配对照：年化不低 2pp、Sharpe 不低 0.10、近一年不低 3pp

2× 是项目标准成本的加倍口径，已经比普通佣金、印花税和 5bp 滑点假设更保守。

### 3. 严重成本压力（强制）

优先使用 3×；若历史证据只保留 5×，则用 5× 作为更严格的可用压力证据。

- 年化 >= 5%
- Sharpe >= 0.80
- MDD 不深于 -25%
- 总收益 > 0
- 近一年 >= -2%

### 4. 集中度（强制，使用毛利润口径）

- top1 毛利润贡献 <= 20%
- top3 <= 45%
- top5 <= 65%
- 最大行业毛利润贡献 <= 40%
- 最大单票亏损 <= 10% 毛利润
- 股票宽度 >= max(40, 4 × 最大持仓数)
- 多资产候选单一资产贡献 <= 50%

净收益集中度只报告，不作为独立硬否决。历史证据如果只保留 2× 净集中度门槛，可仅用 2× 净门槛作为缺失毛利润数据时的回退；5× 净集中度绝不作为硬门槛。

### 5. 5× 极端诊断（非硬否决）

5× 出现负年化、负总收益、相对严重压力回撤恶化超过 5pp，或净利润/毛利润低于 10% 时，只记录警告并转人工复核。

## 判定状态

- `qualified_for_paper_review`：所有强制门槛通过，可进入纸面复核，不代表可生产。
- `rejected`：至少一个强制门槛失败，仍不推进。
- 历史旧预注册的 `all_pass=false` 和 `selected=null` 保持不变；v2 结论只写入独立 sidecar。
